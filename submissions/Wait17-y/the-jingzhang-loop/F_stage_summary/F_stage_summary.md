## Core Framework

### The Jingzhang Loop (Three-Layer Strategic Framework)

```
Innovation Loop (how innovation happens)
    AI innovation 6-stage cycle -> defines spatial requirements
        |
        v
Spatial Loop (how space is organized)
    One Axis + Three Districts + Five Nodes -> spatial configuration
        |
        v
Infrastructure Loop (how the city sustains innovation)
    5 sub-cycles (openness/mobility/data/sharing/operations) -> continuous operation
```

### One Axis, Three Districts, Five Nodes

**One Axis**: Jingzhang Heritage Park - Developer Corridor (8.7 km linear public space spine)

**Three Districts**:

| District | Role | Core Spatial Strategy |
|----------|------|----------------------|
| Zhongzhi Park (192.1 ha) | Research Core | Boundary Interface Model: activate edges, preserve walls |
| AI Yuandian Community (104.3 ha) | Collaboration Hub | Collision Hub + Elastic R&D + 24h Zone |
| Dazhongsi (72.0 ha) | Application District | Urban Sandbox + AI Product Debut Hall + Citizen AI Participation |

**Five Nodes**: Knowledge Origin -> Open Source Engine -> Collision Hub -> Experiment Platform -> Market Interface

### Three Thematic Lines

| Line | Theme | Function |
|------|-------|----------|
| Heritage Line | Jingzhang Railway cultural memory | Connect past innovation to future AI |
| Experience Line | Public AI encounter zones | Citizen-level AI literacy and engagement |
| Frontier Line | Cutting-edge AI R&D interface | Global researcher and developer attraction |

## Key Constraints (DO NOT VIOLATE)

1. Spatial boundaries = provisional bbox, NOT planning boundaries
2. All metrics = Innovation Capacity, NOT Planning Requirements
3. All spatial measures = "conceptual suggestions"
4. 5 planning control items ALL MISSING (FAR/height/density/green ratio/setback)
5. Campus walls: activate edges only, never propose demolition
6. Citizens = AI innovation participants, NOT test subjects
7. International visitors = IVSS spatial services, NOT visa policy
8. AI-assisted generation (Codex GPT-5), recorded in agent.json
